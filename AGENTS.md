# Agent Instructions

This file contains instructions and context for AI coding agents working on this project.

## Project Overview

ConventionalCommits.org is a Hugo-based static website that hosts the Conventional Commits specification in multiple languages.

## Deployment

See `./deployment_plan.md` for current deployment status and instructions.

## Development

- Static site generator: Hugo
- Local development: `docker-compose up` or `hugo server`
- Build command: `hugo`
- Output directory: `public/`

See CONTRIBUTING.md for guidelines on adding translations and contributing to the specification.
